# 数据来源与字段

- 官方页面：https://archive.ics.uci.edu/dataset/332/online+news+popularity
- 下载地址：https://archive.ics.uci.edu/static/public/332/online+news+popularity.zip
- 名称：Online News Popularity，UCI Machine Learning Repository，2015 年。
- 数据集许可：CC BY 4.0，https://creativecommons.org/licenses/by/4.0/ 。再分发或改编时保留来源与署名。
- 提供者：Kelwin Fernandes、Pedro Vinagre、Paulo Cortez、Pedro Sernadela（以官方页面署名为准）。
- 原始文章版权属于 Mashable。本项目只使用数据集提供的数值统计特征，不复制新闻正文。
- 本次下载的 CSV 实测为 39,644 行、61 列；官方页面及随附说明写 39,797 条，报告以 CSV 实际读取为准，不增加或补造样本。
- CSV 的 SHA-256、实测行数、缺失值数量见 `../results/data_quality.json`；原始 `.names` 字段说明一并保留。

本项目选择以下 10 项特征，方便期末网页输入；舍弃其余特征属于项目简化，不是对全部字段最优性的结论。

| 字段 | 中文含义 | 输入范围 |
|---|---|---|
| n_tokens_title | 标题词数 | 非负整数 |
| n_tokens_content | 正文词数 | 非负整数 |
| num_hrefs | 链接数 | 非负整数 |
| num_imgs | 图片数 | 非负整数 |
| num_videos | 视频数 | 非负整数 |
| average_token_length | 平均词长 | 非负数 |
| num_keywords | 元数据关键词数 | 非负整数 |
| global_subjectivity | 文本主观性 | 0 至 1 |
| global_sentiment_polarity | 文本情感极性 | −1 至 1 |
| is_weekend | 是否周末发布 | 0 或 1 |

目标字段 `shares` 是社交分享次数，以 `shares >= 1400` 定义热门新闻（1），其余为普通新闻（0）。1400 为本项目固定阈值，不从测试集优化。URL、采集间隔、分享次数不作为输入，也不使用引用新闻分享量等可能产生时间信息混用的字段。

主观性与情感极性来自数据集已有统计特征。网页不内置英文文本情感提取器，也不声称可以直接预测任意中文文章。随机分层划分仅评价同分布历史数据，不等同未来时间外验证。
